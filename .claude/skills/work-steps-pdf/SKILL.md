# 作業工程PDF（動画仕上げの標準フォーマット）

フウガ決定（2026-10-01）：動画を作るときの作業手順は、必ずこの形式で渡す。
見本：`assets/example_ep01.html`（第1話「人生は、短くない。」、5ページ）

## 手順

1. **材料を集める**：その回のtodo、台本・ナレーション原稿、挿絵の配置リスト、概要欄（`epXX_description.md`）、差し替え素材（END・文字画面・テロップ・アイコンなど）
2. **素材フォルダを用意**：`company/production/epXX_parts/` に差し替え素材をまとめる
3. **HTMLを書く**：`assets/template.html` を `epXX_parts/work_steps.html` にコピーして中身を埋める
   - 細かい書き方は `assets/example_ep01.html` を見て合わせる
4. **PDFにする**：`scripts/render.sh company/production/epXX_parts/work_steps.html company/production/epXX_parts/epXX_work_steps.pdf`
5. **自分で確認**：PDFをReadで開いて、画像が出ているか、ページの切れ目で見出しだけ残っていないかを見る（切れていたら、その見出しに `class="pb"` をつけて改ページする）
6. **todoと対応させる**：その日のtodoファイルに作業工程PDFのパスを書き、①②…の番号を工程表と一致させる
7. **渡す**：SendUserFile（display: render）でPDFを送る。コミットしてpushする

## 構成（この順番を守る）

1. **タイトル**：「第◯話「タイトル」／仕上げの作業工程」＋サブ行（真面目の芽 ／ 日付 ／ 流れ）
2. **全体の流れ**：表（順・やること・todo番号・目安）＋合計時間のバッジ＋「順番のコツ」の黄色メモ
3. **工程ごとのセクション**：緑の線の見出し＋「todo番号 ／ 目安時間」バッジ
   - 手順は番号付きリストで短く。Vrewのメニュー名は「バージョンで違うかも」と添える
   - 差し替える画像・素材は `.parts` でサムネイルを並べる（ファイル名＋用途）
   - 文言・タイミングがあるものは表（時間・画像・文言）
   - 最後に□チェックリスト（`ul.ck`）。コツ・注意は `.note`（黄）、危ないことは `.warn`（赤）
4. **書き出して通しで見る**：書き出し設定（MP4・1080p）＋確認チェックリスト
5. **概要欄の時間を直す**：目次・予定・実際（メモ）の表
6. **アップロード**：タイトル・サムネのパス・概要欄のファイル＋チェックリスト

## 書き方のルール
- フウガが作業しながら見る前提。1工程＝1見出し、1行は短く
- 「やる前にやると楽になること」は全体の流れの下に必ず1つ書く
- 古いファイルは消さずに `_old` をつけてよける、と書く
- 目安時間は現実的に。合計もバッジに出す

## デザイン
- A4縦、Noto Sans CJK JP（なければIPAゴシックに自動フォールバック）
- 本文 #2b211a、アクセント緑 #2e7d32、見出し背景 #f3efe6、メモ #fff7d6＋#FFD400
- CSSは `assets/template.html` のものをそのまま使う（変えない）
