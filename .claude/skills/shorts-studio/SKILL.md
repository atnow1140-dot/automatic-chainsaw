# ショート動画スタジオ（フウガの定型プロンプト集）

フウガが作った「ショート動画を1本作って投稿するまで」の型。依頼に合う工程だけを実行する。
各工程のプロンプト本文は `references/prompts.md`、調べものの品質ルールは `references/research-rules.md` にある。**実行前に、使う工程の本文を必ず読む。**

## 工程と対応するプロンプト（投稿までのチェックリスト順）

| # | 工程 | こう言われたら | プロンプト |
|---|---|---|---|
| ① | 伸びてるテーマを調べて1つ選ぶ | 「今伸びてるテーマは？」「トレンドを調べて」 | prompts.md「①トレンド分析」＋ research-rules.md |
| ② | 台本（約50秒・Vrew用CSV） | 「台本を作って」「CSVで」 | prompts.md「②台本」 |
| ③ | 冒頭2秒のフックを10個 | 「フックを出して」「最初の一言」 | prompts.md「③フック」 |
| ④ | タイトル案10個 | 「タイトル案」 | prompts.md「④タイトル」 |
| ⑤ | サムネのパワーワード5個 | 「サムネの文言」 | prompts.md「⑤サムネ」 |
| ⑥ | 伸びたテーマの横展開10個 | 「次のネタ」「横展開」 | prompts.md「⑥横展開」 |
| ⑦ | ハッシュタグ3個＋概要欄 | 「ハッシュタグ」「概要欄」 | prompts.md「⑦ハッシュタグ・概要欄」 |
| 調 | Xで話題・困りごとを調べる | 「Xで何が話題？」 | prompts.md「調A：X調査」＋ research-rules.md |
| 調 | 調査結果からネタ10個 | 「調べた結果からネタを出して」 | prompts.md「調B：調査からネタ出し」 |
| 調 | 伸びている「型」の分析 | 「伸びてる型を分析して」 | prompts.md「調C：型の分析」＋ research-rules.md |

「全部やって」「1本作って」と言われたら ①→②→③（フックを②の1行目に反映）→④→⑤→⑦ の順に通しでやり、最後に下の「投稿までのチェックリスト」を埋めて返す。

## 動かし方のルール

- **止まらない**: 途中で分からないことがあってもフウガに質問して止まらない。いちばん可能性の高い前提で進め、前提は最後に書く。
- **テーマが空欄のとき**: 直前の会話・`company/majime-no-me/` の最新エピソード・①の結果の順で決める。決めたテーマは冒頭に1行で書く。
- **調べものが入る工程（①・調A・調C）は `references/research-rules.md` を全部守る**（出典URL・日付・事実と推測の分離・◎○△・デメリット・確認ポイント3つ・次にやること1つ・意外な切り口1つ）。
- **ツールの読み替え**: 元のプロンプトにある「Gemini」「Grok」は、ここではWeb検索（WebSearch／WebFetch）で代わりに調べる。XやYouTubeの中身が直接読めないときは、読めなかったことをはっきり書き、数字は「未確認」にする。作り話の数字・URL・タイトル例は絶対に出さない。
- **CSVの出力**: ②の台本は `No,内容` のCSVで出し、依頼がなくてもファイルにも保存する（下の「保存先」）。テロップに半角カンマが入るときは、その行をダブルクォートで囲む。

## 真面目の芽（フウガのメインチャンネル）で使うときの上書きルール

このスキルの元プロンプトは「恐怖を煽る」「それ、実はヤバいんです」など強めの型。**真面目の芽の動画に使うときは、`company/majime-no-me/CLAUDE.md` の表現ルールを優先する**:
- 煽らない。フックは「常識を問い直す」「数字で気づかせる」を使い、「恐怖を煽る」切り口は使わない
- 口調は「仲の良い先輩」ではなく、問いかけ中心の落ち着いた常体（「〜じゃない？」「〜かな」）
- ②のアクションは「コメントで教えて」でOK。ただし「必ず」「今だけ」は使わない
- 「一般的な金融教育です。個別の投資助言ではありません」を概要欄（⑦）に必ず入れる
- 真面目の芽以外のテーマ（例：サメの雑学）なら、元プロンプトどおりでよい

## 保存先

- 真面目の芽の動画: `company/majime-no-me/episodes/epNN_テーマ/` に `short-<テーマ>.csv`（台本）と `short-<テーマ>.md`（フック・タイトル・サムネ・ハッシュタグ・概要欄）
- それ以外のテーマ: `company/secretary/ideas/shorts/YYYY-MM-DD_<テーマ>.md`（CSVも同じ場所に）
- 調査結果（①・調A・調C）: `company/secretary/ideas/research/YYYY-MM-DD_<調べた内容>.md`
- 保存したらコミットしてプッシュし、何を保存したかを一言で伝える

## 投稿までのチェックリスト（通しでやったときの最後に埋める）

- [ ] 今伸びてるテーマを調べて、1つ選んだ（①）
- [ ] 選んだテーマで台本を作った（②）
- [ ] 冒頭のフックを、一番強い一言に磨いた（③）
- [ ] タイトルとサムネ文言を決めた（④・⑤）
- [ ] 台本（CSV）をVrewに貼り付けて動画にした ← フウガの作業
- [ ] ハッシュタグ2〜3個で、夜19時45分に予約投稿した（⑦） ← フウガの作業
- [ ] 伸びたら、その路線を横展開して次を量産（⑥）
