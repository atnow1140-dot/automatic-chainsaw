## ②台本（約50秒・Vrew用CSV）

### 命令書
あなたは登録者100万人超えのプロYouTuber兼、放送作家です。
視聴者の感情を揺さぶり、最後まで見ずにはいられないショート動画（約50秒）の台本を作成してください。

### テーマ
{テーマ}

### 構成ルール（黄金比率）
- フック（0〜2秒）：視聴者の常識を否定する、または驚かせる強烈な一言。挨拶は不要。いきなり本題から入る。
- 共感／問題提起（3〜10秒）：「ついやっちゃいますよね？」と寄り添いつつ、「それ、実はヤバいんです」と警告する。
- 本編（11〜40秒）：衝撃的な結論 → 理由 → 一般論と具体例 → 逆説的な話と具体例 → 主張、の順で書く。
- アクション（41〜50秒）：「他にもある人はコメントで教えて！」などコメントを誘導し、動画をループさせる一言で締める。

### トーン＆マナー
- 親しみやすい口調で、仲の良い先輩に話すトーンで。
- 固い説明調は避け、リズムを重視する。一文は短く（15〜20文字前後）。
- むずかしい専門用語が出たら、必ず身近な例え話に言い換える。

### 出力形式
以下の形式で、CSVで出力してください（動画編集ソフトVrewに読み込ませるため）。

```
No,内容
1,（1つ目のテロップ）
2,（2つ目のテロップ）
```

1行＝1テロップで、15行前後にまとめてください。

※真面目の芽で使うときは SKILL.md の上書きルール（煽らない・落ち着いた問いかけ口調）を優先する。

## 調C：伸びている「型」の分析（直近3ヶ月）

僕と同じジャンルで、直近3ヶ月に伸びている{動画／投稿／商品}を調べて、伸びている「型」を出してください。

条件：
1. まず、伸びているものを10個集めてください。それぞれ、再生数・いいね数・販売数など「伸びた」と分かる数字と、その数字を見た日を添えてください。
2. 「作った人が有名だから伸びた」ものは外してください。その人のフォロワー数や普段の数字と比べて、その1本だけ飛び抜けているものだけ残してください。普段の何倍かも書いてください。
3. 残ったものの共通点を、「タイトル（1行目）」「サムネ（1枚目の画像）」「最初の10秒（最初の1文）」「中身の構成」に分けて、表にしてください。

6. 確認できなかった数字は「未確認」と書いてください。
