# 真面目の芽｜チャンネル運用スキル

YouTubeチャンネル「真面目の芽」に関する作業（説明文・キーワード・タグ・ハッシュタグ・概要欄・企画・台本）は、このルールに沿って作る。

## 世界観（すべての出力で一貫させる）
- **キャッチコピー**: 真面目の芽｜まじめな毎日に、選べる余白を。
- **語り手**: 同世代の女性が寄り添う語り
- **テーマ**: お金・人間関係・働き方の「当たり前」を一緒にほどく
- **姿勢**: 正解を急がない。根拠や日常の場面を手がかりに、今日できる小さな選択を探す
- **将来の導線**: スキルで選べる仕事や暮らしを増やす（無料プレミアム動画 → 収益化）
- **やらないこと**: 投資・転職・医療・心理支援などの個別判断を代わりに行わない

## 1. チャンネル説明文（公開初期・確定版）

```
真面目の芽｜まじめな毎日に、選べる余白を。

節約しているのに、お金の不安が残る夜。
断ったあとも、ずっと気になる時。
安定しているのに、安心できない日。

真面目の芽は、お金・人間関係・働き方の「当たり前」を、同世代の女性の声で一緒にほどくチャンネル。
正解を急がない。根拠や日常の場面を手がかりに、今日できる小さな選択を探していく。

お金や働き方に迷う時、選べる仕事や暮らしを増やすためのスキルも、一つの土台になる。

※投資・転職・医療・心理支援などの個別判断を代わりに行うチャンネルではない。
※研究や資料を使う動画は、概要欄に出典と説明の範囲を記載する。
```

| 段落 | 役割 |
|---|---|
| 1行目 | チャンネル名と約束を一瞬で伝える |
| 2〜4行目 | 視聴者が自分の生活を重ねる具体場面 |
| 本文1段落 | お金・関係・働き方というテーマと、女性の寄り添う語りを伝える |
| 本文2段落 | 「スキルで選択肢を増やす」という将来の収益導線の世界観を置く |
| 注記 | 個別の金融・医療・心理判断を扱わないこと、根拠の姿勢を示す |

## 2. 無料プレミアム動画の公開後に追記する文
**無料動画・リンク先・案内内容が実際に公開済みになってから**、説明文の「スキル」の段落の下へ追記する。

```
何から身につけるか迷う時のために、選べる仕事を増やすスキルの考え方を無料プレミアム動画にまとめた
→ [実際の案内ページURL]
```

- 入れない表現：「絶対稼げる」「誰でも変わる」「見るだけで人生が変わる」
- 無料動画は信頼を深める地図であって、成果を保証するものではない

## 3. チャンネルキーワード
YouTube Studioのチャンネルキーワード欄にカンマ区切りで入れる。ブランド名・テーマ・視聴者の悩み・スキルの方向を混ぜる。

```
真面目の芽, まじめの芽, まじめのめ, majime no me, お金の不安, お金の悩み, 節約, 家計, 家計…
```
※元資料（PDF）でこの行が途中で切れている。続きはフウガに確認すること。

**入れないキーワード**
- 他チャンネル名、他者のハンドル、他者の人物名
- 「簡単に稼ぐ」「不労所得」「絶対成功」など、内容と合わない言葉
- 投資助言・医療助言・心理診断と誤解される強い専門語
- 実際に扱わないジャンル名を大量に並べること

## 4. 動画別アップロードタグ
タイトルの丸写しではなく、テーマ・視聴者の言葉・表記ゆれを補うために使う。**1本あたり5〜8個**、内容に関係するものだけ。

| 動画 | タグ候補 |
|---|---|
| 第1話「節約しているのに、お金の不安が消えない夜」 | お金の不安, お金の悩み, 節約, 家計, 家計管理, お金のストレス, 真面目の芽, まじめの芽 |
| 第2話「断ったあとも、ずっと気になるのはなぜ？」 | 断り方, 人間関係, 境界線, 罪悪感, アサーティブコミュニケーション, 頼まれごと, 真面目の芽, まじめの芽 |
| 第3話「安定した道なのに、安心できないとき」 | 働き方, 仕事の悩み, キャリア, 安定, 自己決定, スキルアップ, 選択肢, 真面目の芽 |

## 5. ハッシュタグ
タイトルには入れず、**概要欄の末尾に1〜3個だけ**。毎回チャンネル名タグを1個、残りをその回のテーマにする。

| 動画 | ハッシュタグ |
|---|---|
| 第1話 | #真面目の芽 #お金の不安 #家計 |
| 第2話 | #真面目の芽 #人間関係 #断り方 |
| 第3話 | #真面目の芽 #働き方 #キャリア |
| お金・スキル系の長尺 | #真面目の芽 #スキルアップ #働き方 |

避けること：無関係な人気タグ、広すぎるタグの大量追加、他者ブランド名のハッシュタグ、#簡単に稼ぐ のような煽り。

## 6. 動画概要欄の定型
冒頭の3行（[テーマ] と [今日の小さな選択] を差し替える）：
```
[テーマ]の話。
正解を急がず、今日できる小さな選択を一つ探していく。
今回は、[今日の小さな選択] を試してみよう。
```

根拠を使う回だけ、その下に：
```
【参考】[著者・年・資料名・URL]
この動画で言える範囲：[研究・資料から言えること]
言えないこと：[個別判断や、研究が直接検証していないこと]
```

無料プレミアム動画が公開済みで、その回と自然につながる場合だけ末尾に：
```
選べる仕事を増やすために何から学ぶか迷う時は、プロフィールの無料動画も見てみてね。
```

## 7. 出す前の最終チェック（毎回これで確認してから渡す）
1. 説明の最初の2〜3行だけで、誰のどんな悩みを扱うか分かるか
2. 「お金・人間関係・働き方」と「スキルで選択肢を増やす」が矛盾なくつながっているか
3. 実在しない無料動画・商品・リンクを先に書いていないか
4. キーワード・タグ・ハッシュタグに他者ブランドや無関係な流行語を入れていないか
5. 根拠を使う動画は、概要欄に出典と主張の範囲を入れているか
6. 収益化への導線が、動画の価値を渡した後にだけ現れているか
