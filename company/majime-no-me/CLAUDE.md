# 真面目の芽（MAJIME no ME）プロジェクト

## 概要
- チャンネル: 真面目の芽 ― 大人のための静かな学び／ナビゲーター: シン
- テーマ: お金の置き場・家計・投資の基本を、煽らずにやさしく解説
- 口調: 問いかけ中心の常体（「〜じゃない？」「〜かな」）。答えを押しつけない
- ブランド設定・説明文: `channel/channel-profile.md`

## 1本の動画から作るもの（1エピソード＝3媒体）
1. **YouTube本編**（10〜15分・16:9）… メイン
2. **YouTubeショート**（1本40〜60秒・9:16）… 本編から3本切り出し → 本編へ誘導
3. **Instagram** … ショートと同じ動画をリールで投稿＋要点のカルーセル（文字だけのスライド）→ プロフィールのリンクから本編へ

## 制作の流れ
台本 → Vrew用テキスト → AI画像（Canva） → BGM・効果音 → 最終仕上げシートでチェック → 本編書き出し → ショート3本 → Instagram

## 表現ルール（全媒体共通）
- グラフ・図形・矢印・アイコンは使わない。AI画像（`assets/image-prompt-style.pdf` の画風）＋テロップ＋ナレーションで見せる
- 煽らない（札束・右肩上がり・「必ず」「今だけ」は使わない）
- 「一般的な金融教育であり、個別の投資助言ではありません」を、どの媒体にも必ず入れる
- 制度や数字は、公的な資料（金融庁・日本銀行など）で確認してから使う

## フォルダ構成
```
company/majime-no-me/
├── CLAUDE.md                … このファイル（プロジェクトのルール）
├── channel/                 … チャンネル開設・プロフィール・ブロック単語
├── assets/                  … 全動画共通の素材（画像の画風プロンプト集など）
├── ideas/                   … 本編のネタ帳
└── episodes/
    └── epNN_テーマ/          … 1エピソード分をまとめて置く
        ├── YYYY-MM-DD_テーマ_vN.md          … 本編台本（版を残す）
        ├── ..._vrew.txt / _vrew-guide.md    … Vrew用
        ├── ..._image-prompts.md / _images.md … AI画像
        ├── ..._sound-cues.md                … BGM・効果音
        ├── ..._final-sheet.md               … 本編の最終仕上げシート
        ├── shorts.md                        … YouTubeショート3本
        └── instagram.md                     … Instagram（リール＋カルーセル）
```
