# ブロックする単語リスト｜真面目の芽

## 使い方
- **YouTube**: YouTube Studio → 設定 → コミュニティ → 自動フィルタ → 「ブロックする単語」に貼る
  - 該当コメントは削除ではなく「確認のために保留」に入る → 誤爆しても週1で見て承認すればOK
  - 同じ画面の「不適切な可能性があるコメントを保留」もオン
- **Instagram**: 設定 → 非表示ワード → 「カスタム単語を管理」に貼る
  - 「コメントを非表示」「メッセージリクエストを非表示」の両方をオン
- 新しい手口を見つけたら、下の「追加ログ」に足していく

## ⚠️ ブロックしない単語（本題なので）
投資／NISA／貯金／配当／株／複利／積立 → ここを入れると普通の質問まで保留になる
