# 人物シリーズ 第3話｜本田宗一郎と藤澤武夫　字幕の色指定

作成日: 2026-10-11
ルール（style-guide・人物シリーズ共通）: 基本は白。キーワードだけ黄色、赤は1本で2〜3回まで。最後の「小さな芽」は必ず黄色

## 赤（3か所）
| 字幕 | 赤にする語 | 理由 |
|---|---|---|
| 会社のお金を | お金 | 冒頭フックの「え？」の核 |
| 自分たちの 家族じゃなく | 家族じゃなく | 驚きの事実 |
| 手を抜くことじゃない | 手を抜く | この回のメッセージの核 |

## 黄色（10か所）
| 字幕 | 黄色にする語 |
|---|---|
| ほかの男に まかせていた | ほかの男 |
| ひとりじゃなかったんだよね | ひとりじゃ |
| 本田宗一郎 | 本田宗一郎 |
| 藤澤武夫 | 藤澤武夫 |
| まったく 違うふたり | 違うふたり |
| およそ 25年 続いた | 25年 |
| 45歳の 社員だった | 45歳の 社員 |
| ひとりで 抱え込んでしまう | 抱え込んで |
| 誰かの得意で 埋めてもらうこと | 誰かの得意 |
| 小さな芽を 選べる道に育てていこうか | 小さな芽（固定） |
