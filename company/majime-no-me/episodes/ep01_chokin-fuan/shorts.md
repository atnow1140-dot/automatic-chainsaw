# 第1話｜YouTubeショート 3本

> 元: 本編台本v2「貯金してるのに、なんで将来の不安は消えないんだろう？」

> 役割: 本編の「入口」。結論をぜんぶ言い切らず、「続きは本編で」につなげる
> 本編への誘導: 公開後、YouTube Studioの「関連動画」に本編を設定（ショートの画面に本編へのリンクが出る）

## 共通ルール
- 最初の2秒で「問い」を出す（スクロールを止める）
- テロップは大きめ・1画面1フレーズ
- 画面の右下に「※一般的な金融教育です。個別の投資助言ではありません」を常に小さく表示
- 画像は本編と同じ画風。縦長の画像が必要（下の「画像」欄。横長の画像を使うなら、人物が真ん中に来るように切り抜く）
- BGMは本編と同じ曲の一部を使うと、本編とのつながりが出る

## ショート①｜貯金してるのに、不安が消えないのはなぜ？（約45秒）

**タイトル:** 貯金してるのに、不安が消えないのはなぜ？ #真面目の芽 #お金の勉強
**ねらい:** 本編と同じ問いで、「それ自分だ」を引き出す。本編への一番の入口

**ナレーション（Vrewに貼る）**
```
毎月ちゃんと貯金してる。
なのに、将来の不安が消えない。
そんな感覚、ない？
それ、貯金が足りないせいじゃないかもしれない。
明日の生活費も、半年後の予定のお金も、何十年も先のためのお金も、ぜんぶ一つの残高で見てる。
これを『置き場まぜこぜの罠』って呼んでみる。
残高が多い日は、使いすぎが気になる。
少ない日は、将来が怖くなる。
どっちも、そのお金が何のためか見えてないから起きるんだよね。
じゃあ、どう分ければいいんだろう？
続きは本編で、一緒に考えてみよう。
```

## ショート②｜お金の不安が小さくなる「三つのバケツ」（約55秒）

**タイトル:** お金の不安が小さくなる「三つのバケツ」の話 #真面目の芽 #家計管理
**ねらい:** 本編で一番わかりやすいたとえ話。保存・共有されやすい

**ナレーション（Vrewに貼る）**
```
お金の不安を小さくする、たとえ話を一つ。
ある家に、大きなバケツが一つだけあった。
今日のごはん代も、来月の引っ越し代も、ずっと先のお金も、ぜんぶ一緒。
ある日、急に修理代が必要になって、手が止まる。
どれが今日を守るお金だっけ？
そこで、バケツを三つに分けてみた。
一つ目は『今日を守る』。
生活費と、急な出来事への備え。
二つ目は『近い予定』。
数か月から数年のうちに使うお金。
三つ目は『遠い未来を育てる』。
当分使わない、余裕のあるお金だけ。
問題は、お金の量だったのかな？
それとも、置き方だったのかな？
```
