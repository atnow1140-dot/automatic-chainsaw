# 真面目の芽｜本編ネタ10本（グラフ・図形なし構成）

> 作成日: 2026-09-26
> 方針: グラフ・図形・アイコン・矢印を使わず、**実物（手元の実写）／文字テロップ／ナレーション（例え話）** だけで成立させる
> 共通ルール: タイトルは問いかけ形／煽らない／公的情報を出典にする／「一般的な金融教育であり、個別の投資助言ではありません」を映像・概要欄に入れる
> 第1話（済）: 「貯金してるのに、なんで将来の不安は消えないんだろう？」（三つのバケツ）→ 以下は第1話の続きとして自然につながる順に並べた

---

## ネタ1: 「今日を守るお金」って、いくらあれば足りるんだろう？
- 概要: 第1話の一つ目のバケツ（生活防衛資金）を深掘りする回
- 構成の骨組み: 不安の声 → 「何か月分」と言われる理由 → 自分の生活費の出し方 → 仕事や家族で必要な額が変わる話 → 今日からやること
- 図なしの見せ方: **封筒**に「家賃」「食費」などと書いて並べる手元の実写。金額は「例」と明記したテロップで1つずつ
- 次のアクション: 生活費の目安として紹介する公的資料・調査を探す

## ネタ2: 毎月の支出、なんでちゃんと把握できないんだろう？
- 概要: 家計簿が続かない真面目な人向け。「全部記録する」をやめる考え方
- 構成の骨組み: 続かないあるある → 続かないのは意志の弱さではなく仕組みのせい → 固定費と変動費に分けるだけ → 月1回10分の見直し（第1話とつなげる）
- 図なしの見せ方: **実物のレシート**を「毎月同じ」「毎月違う」の2つの山に分けていく手元の実写
- 次のアクション: 撮影用のレシート（個人情報なし）を用意する

## ネタ3: 「固定費を見直そう」って、どこから手をつければいい？
- 概要: 通信・保険・サブスクなど、一度見直すと効果が続く固定費の話
- 構成の骨組み: 節約疲れの共感 → 1回の見直しが毎月効いてくる理由 → 見直す順番を3つ → やりすぎ注意（必要な保障まで削らない）
- 図なしの見せ方: 見直す項目を**チェックリストの文字だけ**で1行ずつ出す。ナレーションで「毎月○円なら1年で○円」を例として話す
- 次のアクション: 例に使う金額を決める（特定の会社名や商品名は出さない）

## ネタ4: 投資で「減る」って、どういうことなんだろう？
- 概要: 値下がり（価格変動）リスクの意味を、怖がらせずに正しく伝える回
- 構成の骨組み: 「投資＝損する」のイメージ → 値段は毎日上下するもの → 「減る」には一時的な値下がりと、そのお金を使うときに損が確定するケースがある → だから使う時期が大事（第1話の三つのバケツに戻る）
- 図なしの見せ方: **野菜の値段が季節で変わる**という例え話と、スーパーの値札の実写（撮影許可が取れなければ自作の値札）
- 次のアクション: 金融庁の資料で、リスクの説明の言い回しを確認する

## ネタ5: 「卵をひとつのカゴに盛るな」って、どういう意味？
- 概要: 分散投資の考え方を、ことわざをそのまま実演して伝える回
- 構成の骨組み: ことわざの紹介 → 一つに集中させた場合の話 → 分けると何が変わるか → 分けても損が出ないわけではない、という注意
- 図なしの見せ方: **実物の卵とカゴ**。1つのカゴに全部入れる／いくつかのカゴに分ける、を手元の実写で見せる
- 次のアクション: 卵・カゴ・背景の布を用意し、実写のテスト撮影をする

## ネタ6: 複利って、ほんとに"魔法"なのかな？
- 概要: 「複利は魔法」という煽り表現を、落ち着いて分解する回
- 構成の骨組み: 「魔法」という言葉への違和感 → 複利とは「利益にも利益がつく仕組み」 → 時間が味方になる理由 → 利回りは保証されないし、下がる年もある
- 図なしの見せ方: 定番の右肩上がりグラフは使わない。**数字を1年ごとに1行ずつテロップ**で出して積み上げ、「例」「保証ではない」と明記する。例え話は小さな芽が育つ話（チャンネル名とつなげる）
- 次のアクション: 例の計算を秘書が作る → 金額と利回りの前提を確認する

## ネタ7: NISAって、結局なにが「お得」なんだろう？
- 概要: 「お得」の正体は「利益に税金がかからない」という一点、と整理する回
- 構成の骨組み: よく聞くけど説明できない → 普通は利益に税金がかかる → NISAではそれがかからない → 元本保証ではない → 自分に合うかを考える順番（第1話の三つ目のバケツ）
- 図なしの見せ方: 定義を**文字カード**で出す（第1話のNISAパートと同じ見せ方）。具体的な商品・証券会社・売買画面は出さない
- 次のアクション: 金融庁のNISAサイトで最新の制度内容を確認する（制度変更に注意）

## ネタ8: ボーナス、どう置いたらいいんだろう？
- 概要: まとまったお金が入ったときの考え方。三つのバケツの応用回
- 構成の骨組み: 「つい使っちゃう」「全部投資すべき？」の迷い → まず三つのバケツの足りないところを埋める → 残ったら「いつ使う？」で分ける → ご褒美を使うのもOK
- 図なしの見せ方: **瓶3つ**（第1話のバケツを実物にしたもの）に、お札に見立てた紙を分けて入れていく手元の実写
- 次のアクション: 公開時期をボーナスの時期（6〜7月・12月）に合わせるか決める

## ネタ9: SNSの"うまい話"、どうして真面目な人ほど引っかかるんだろう？
- 概要: 投資詐欺・なりすましの手口と、見分ける問いを伝える回（チャンネルの「DMで勧誘しない」宣言ともつながる）
- 構成の骨組み: 真面目で勉強熱心な人ほど狙われる理由 → よくある誘い文句（「必ず」「今だけ」「あなただけ」） → 立ち止まるための3つの問い → 相談先（公的な窓口）
- 図なしの見せ方: 誘い文句を**文字だけ**で次々に出し、ナレーションで一つずつ問い返す。実際のアカウント・画面は使わない
- 次のアクション: 金融庁・消費者庁の注意喚起ページで最新の手口と相談窓口を確認する

## ネタ10: 年金って、ほんとにもらえなくなるのかな？
- 概要: 「年金はもらえない」という不安を、公的な情報をもとに落ち着いて整理する回
- 構成の骨組み: よく聞く不安 → 年金の仕組み（ざっくり） → 「もらえない」と「減るかもしれない」の違い → 自分の見込み額の調べ方（ねんきん定期便・ねんきんネット） → 三つのバケツとのつながり
- 図なしの見せ方: **実物のねんきん定期便**（個人情報は隠すか見本を使う）を手元で見せ、見るべき欄をナレーションで案内する
- 次のアクション: 日本年金機構・厚生労働省の資料で、説明に使う表現を確認する

## 見せ方の分類（撮影準備の目安）
- 文字テロップ＋ナレーションだけで作れる: ネタ3, 7, 9
- 手元の実写が必要（小物を用意する）: ネタ1, 2, 5, 8
- 実写と文字の組み合わせ: ネタ4, 6, 10

## 図なしで作るときの注意
- 「右肩上がりのグラフ」「札束」「急上昇」など、煽る映像は使わない（第1話のサムネの方針と同じ）
- 数字を出すときは1画面に1つだけにし、「例」「保証ではない」を添える
- 実写の小物（瓶・封筒・卵など）はシリーズを通して同じものを使うと、チャンネルの「らしさ」になる
