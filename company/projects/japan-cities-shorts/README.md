# Japan Cities Shorts（アメリカ向けショート動画）

作成日: 2026-09-27

## 概要
- ターゲット: アメリカ（英語圏）の視聴者
- 内容: 日本の47都道府県から1都市ずつ、写真・映像をテンポよく見せる縦型ショート（言葉なしでも伝わる）
- 本数: 47本（1都道府県＝1本）

## 都市の選び方
- 基本は県庁所在地
- 海外でより有名な都市がある県は入れ替え（`cities.csv` の type が famous のもの）
  - 例: 栃木→日光、群馬→草津、埼玉→川越、山梨→富士河口湖、岐阜→高山、三重→伊勢、和歌山→高野山、大分→別府、福島→会津若松
- 一覧: `cities.csv`（番号・県名・都市名・英語検索キーワード）

## 動画フォーマット（案）
- 縦 1080×1920、15〜30秒
- 1カット 0.5〜1.5秒でテンポよく切り替え、BGMのビートに合わせる
- テキストは最小限: 冒頭に都市名（例: "KYOTO, JAPAN"）、最後に "Which city next?" など
- 1本あたり素材の目安: 写真 8〜12枚＋動画 3〜5本

## 素材のルール（収益化のため必須）
- 使うのは **商用利用OK・クレジット不要** の素材サイトのみ
  - Pexels（Pexels License）
  - Pixabay（Pixabay Content License）
- Google画像検索や一般サイト・SNSの画像は使わない（著作権侵害・収益化停止のリスク）
- どの素材をどこから取ったかは `credits.csv` に自動記録（クレジット不要でも、問い合わせ対応のため残す）
- 注意: 素材だけを並べた動画は、YouTubeの「独自性の低いコンテンツ」と判断される可能性がある
  → 編集（テンポ・構成・テキスト・シリーズ性）で独自性を出す。可能なら自分で撮った映像やオリジナルのマップ演出を混ぜる

## 素材の集め方
1. Pexels / Pixabay で無料のAPIキーを取得
2. 下記を実行（Python 3 のみで動く。追加インストール不要）
   ```
   export PEXELS_API_KEY=取得したキー
   export PIXABAY_API_KEY=取得したキー
   python3 tools/fetch_media.py --only 13        # まず東京だけで試す
   python3 tools/fetch_media.py                  # 47都市すべて
   ```
3. `media/<番号>_<県>_<都市>/photos` と `videos` に保存される
4. 地方都市は素材が少ないことがある → 足りない都市はキーワードを `cities.csv` で調整して再実行

## 保存場所の注意
- 動画ファイルは重い（47都市で数GB〜十数GB）ので、GitHub には入れない（`media/` は .gitignore 済み）
- 実行は自分のPCで行い、Googleドライブ等に保管するのがおすすめ
