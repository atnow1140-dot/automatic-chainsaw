# 海外向けショート動画プロジェクト（Japan Cities）

このフォルダで作業するときの前提。フウガから「海外向けショート」「Japan Cities」と言われたらこのプロジェクト。

## 目的
- アメリカ（英語圏）向けに、日本の47都道府県から1都市ずつ紹介する縦型ショートを47本作る
- 言葉なしでも伝わる、写真・映像をテンポよく見せる動画
- 最終目的はマネタイズ（YouTubeショート収益＋将来的に旅行系アフィリエイト等）

## ファイル
| ファイル | 役割 |
|---|---|
| `README.md` | 企画・動画フォーマット・素材ルール・素材の集め方 |
| `cities.csv` | 47都市リスト（番号・県・都市・英語検索キーワード） |
| `progress.md` | 47本の進捗表（素材→編集→投稿） |
| `templates.md` | 英語のタイトル・説明文・ハッシュタグ・動画構成のテンプレ |
| `tools/fetch_media.py` | Pexels / Pixabay から素材を自動収集するスクリプト |
| `media/` | 収集した素材（重いので git 管理外。フウガのPC/Googleドライブで保管） |

## 守るルール
- 素材は Pexels / Pixabay など **商用OK・クレジット不要** のものだけ。Google画像検索や一般サイトの画像は使わない
- 素材の出典は `media/<都市>/credits.csv` に残す
- 素材の羅列にならないよう、編集（テンポ・構成・テキスト・シリーズ性）で独自性を出す
- 英語は短く・簡単に。テキストは最小限

## 作業の進め方（1本あたり）
1. `tools/fetch_media.py --only <番号>` で素材を集める（フウガのPCで実行）
2. 素材から写真8〜12枚＋動画3〜5本を選ぶ
3. `templates.md` の構成で編集（CapCut / Vrew / Canva など）
4. タイトル・説明文・ハッシュタグを `templates.md` から作る
5. 投稿したら `progress.md` を更新
