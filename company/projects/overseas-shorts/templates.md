# テンプレート（海外向けショート動画）

## 動画の構成（15〜25秒・縦1080×1920）
| 時間 | 内容 | テキスト（英語・画面上） |
|---|---|---|
| 0〜1.5秒 | いちばん映える1カット（動画推奨）でつかむ | `{CITY}, JAPAN 🇯🇵` |
| 1.5〜18秒 | 写真・動画を0.5〜1.5秒ずつ、BGMのビートに合わせて切り替え | 名所名を小さく（例: `Fushimi Inari`）※任意 |
| 18〜22秒 | 夜景・夕景など締めの1カットを長めに | `#{NO} / 47` |
| 最後 | 次回への引き | `Which city next? 👇` |

- 1本目から「#13 / 47」のようにシリーズ番号を入れて、全47本を集めたくなる形にする
- 音楽: YouTubeショートのアプリ内の音楽、または YouTube オーディオライブラリ・Pixabay Music（商用OK）を使う
- 最初と最後の絵をつなげる（ループ再生で気づかれにくい）と視聴維持率が上がりやすい

## タイトル（100文字以内。短いほどよい）
```
{CITY}, Japan in 20 seconds 🇯🇵 #{NO}/47
```
別案:
```
Would you visit {CITY}, Japan? 🇯🇵
{CITY} — Japan's hidden gem ✨
```
※「hidden gem」は東京・京都・大阪など有名都市には使わない

## 説明文
```
{CITY}, {PREFECTURE} — Japan 🇯🇵
Part #{NO} of 47: one city from every prefecture in Japan.

📍 Featured: {SPOT1}, {SPOT2}, {SPOT3}
Follow to see all 47 prefectures!

#Japan #{CITY} #JapanTravel #VisitJapan #Shorts
```

## ハッシュタグ（固定＋都市ごと）
- 固定: `#Japan #JapanTravel #VisitJapan #Shorts #TravelJapan`
- 都市ごと: `#{CITY}` `#{PREFECTURE}` ＋名所1つ（例: `#FushimiInari`）
