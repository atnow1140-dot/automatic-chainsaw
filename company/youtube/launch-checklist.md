# チャンネル開設チェックリスト｜真面目の芽

> パスワードや認証コードは、このファイルやリポジトリには絶対に書かない（パスワード管理アプリへ）。

## 共通（最初にやる）
- [ ] チャンネル専用のGmailを作る（個人アドレスと分ける）
- [ ] YouTubeとInstagramで同じハンドルを確保（例: @majime_no_me）
- [ ] 両方で2段階認証をオン（お金系は乗っ取り・なりすましの標的になりやすい）

## YouTube
### 開設時
- [ ] **ブランドアカウント**でチャンネルを作る（個人名のGoogleアカウント直下にしない。後で共同管理者を追加できる）
- [ ] **電話番号で確認（機能の有効化）** ← 忘れると15分を超える動画がアップできない／サムネを自作画像にできない
- [ ] ハンドル設定（@majime_no_me）
- [ ] 国／地域を「日本」に（収益化の審査・税金に関係）
- [ ] 視聴者設定：チャンネル全体を「子ども向けではない」に（子ども向け扱いだとコメント・一部広告が使えない）

### 見た目
- [ ] アイコン（YouTubeマークなしの版推奨）
- [ ] バナー：2560×1440で作り、**中央1546×423の中に文字・ロゴを収める**（スマホではそこしか見えない）
- [ ] 透かし（右下の登録ボタン）設定
- [ ] チャンネル説明文・リンク（Instagram）・ビジネス用メール（専用Gmail）を登録

### アップロードのデフォルト設定（最初に入れておくと毎回楽）
- [ ] 説明文テンプレ（免責文・なりすまし注意・Instagramリンク）
- [ ] カテゴリ：教育／言語：日本語
- [ ] 有料プロモーションがある動画は、毎回「有料プロモーションを含む」にチェック

### コメント対策（お金系は必須）
- [ ] 「不適切な可能性があるコメントを保留」をオン
- [ ] ブロックする単語を登録（例: LINE, ライン, 副業, 必ず儲かる, 配当保証, DMください, 投資グループ）
- [ ] なりすまし対策として、固定コメントや説明文に「DMで勧誘しない」を明記

### そのあと
- [ ] 再生リストを作る（本編／ショートの結論まとめ など）
- [ ] 収益化条件が近づいたらAdSense準備

## Instagram
- [ ] **プロアカウント（クリエイター）に切り替え**（インサイト＝分析が見られる）
- [ ] カテゴリ：教育 など
- [ ] プロフィールに電話・メールの連絡先ボタンを**出さない**設定を確認（個人情報の公開防止）
- [ ] アイコンは丸く切り抜かれる前提で確認
- [ ] 名前欄・自己紹介・リンク（YouTube）を設定
- [ ] 「非表示ワード」をオン＋カスタム単語登録（DM・コメントの勧誘スパム対策）
- [ ] ストーリーズハイライト用のカバー（例: はじめに／三つのバケツ／YouTube）を用意
