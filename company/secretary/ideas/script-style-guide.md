# 台本の口調スタイルガイド

## 概要
- 「50代アナログ職場でAIを試してみた」シリーズの台本セリフは、台本②（company/secretary/ideas/chiiki-unso-haisya-jimu-script.md）のトーンを基準に統一する
- 以降、新しい話数の台本を作るときはこのガイドに沿って書く

## 詳細（ルール）

### 基本トーン
- 「〜です・ます」は使わない。全部タメ口
- 独り言・実況っぽい温度感（誰かに説明してる感じじゃなく、自分の体験を語ってる感じ）
- 口語表現を要所に入れる：「ぶっちゃけ」「マジで」「まるっと」「とりあえず」など

### 各パートの型（台本②の実例）
| パート | 型 | 台本②の実例 |
|---|---|---|
| フック | うちの〇〇、△△しかない。AIの研修?そんなのないよ。だから50代の[役職]のおっさんが、とりあえず自分で試してみた。 | うちの運送会社、配車表も伝票も全部紙と電話。AIの研修?そんなのないよ。だから50代の配車担当のおっさんが、とりあえず自分で試してみた。 |
| 共感 | 周り（同僚・関係者）の「AIなんて〇〇」って空気を出してから、ぶっちゃけ自分も最初はそう思ってた、で受ける | ドライバーも事務員も「AIなんてうちには関係ない」って空気。ぶっちゃけ僕もそう思ってた。 |
| 実演①② | 「試したのがこれ。〇〇するだけで、△△が1分で出てくる。今まで××するのに◯分かかってたのに。」の型でBefore/Afterの時間差を数字で言い切る | ドライバーからの音声報告をAIに渡すだけで、日報の下書きが1分で出てくる。今まで電話で聞き取って紙に書き写すのに、1件10分はかかってたのに。 |
| 気づき | 「研修なんてなくても、触ってみたら普通にできた。〇〇って思い込んでただけやったなってマジで思った。」 | 研修なんてなくても、触ってみたら普通にできた。「うちの業界には関係ない」って思い込んでただけやったなってマジで思った。 |
| オチ＋CTA | 「50代の[役職]のおっさんでもできたんやから、あんたもできるって。使ったAIとやり方はコメントで聞いて。保存して後で試してみて。」 | 50代の配車担当のおっさんでもできたんやから、あんたの会社でもできるって。使ったAIとやり方はコメントで聞いて。保存して後で試してみて。 |

### NGなこと
- 敬語・丁寧語（〜です、〜ます、〜でしょう）
- 説明口調（「〜という機能があります」のような紹介文っぽい言い方）
- ツール名や数字をぼかす（「なんかAI」「けっこう速い」ではなく「Notta」「1分」など具体的に言い切る
