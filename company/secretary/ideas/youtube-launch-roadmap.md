# YouTubeチャンネル ローンチロードマップ

## 概要
Instagram前提で作った素材(コンセプト・ターゲット・独自ストーリー・マスコット・台本)は
そのまま流用し、YouTubeチャンネル開設 → ショート動画3本 → 15分超の長尺動画1本、
という順番でローンチするまでの手順をまとめる。

## なぜこの順番か
- **ショート3本を先に出す理由**: 制作が軽く、チャンネルの雰囲気・キャラクターを早く固められる。最初の視聴者・登録者を作るのに向いている
- **長尺動画を後に置く理由**: ショートで培った台本・キャラ・世界観を土台に、内容を掘り下げた「保存版」を作れる。また、YouTubeパートナープログラムの収益化条件(登録者1000人+視聴時間4000時間 または ショート再生1000万)のうち、**視聴時間4000時間は長尺動画の方が圧倒的に貯まりやすい**ので、早めに長尺フォーマットを試しておく価値がある

## Phase1: チャンネル開設・基盤整備(目安1-2日)
- [ ] チャンネル名決定(既存プロフィール設計の「フウガ｜デジタルが苦手でもできるAI活用術」を流用)
- [ ] アイコン設定(マスコット男性キャラ assets/mascot-male-final.webp を正方形にトリミング)
- [ ] チャンネルアートバナー作成(マスコット+コンセプトの一言「人生100年時代、マネするだけで活用できるAI」)
- [ ] 概要欄作成(下記たたき台を使用)
- [ ] 再生リストを1つ作成(「ChatGPT100選シリーズ」用の空リストを先に用意)

### 概要欄たたき台
```
人生100年時代。デジタルが苦手でも大丈夫。
今から始める、暮らしと仕事に役立つAI活用術。

社内にAI導入の研修もない、地域密着の中小企業で働きながら
独学でAIに挑戦し、仕事の効率化に成功した経験を発信しています。

マネするだけで使えるAI活用術を、週◯回更新中。
チャンネル登録して、続きをお待ちください。
```

## Phase2: ショート動画3本(目安1-2週間)
既存の台本フォーマット(顔出しなし・イラスト+実写ハイブリッド・AI音声)をそのままYouTube Shorts仕様(縦型、60秒〜最大3分)に流用。

| 本数 | テーマ | 元ネタ |
|---|---|---|
| ショート1 | 音声入力ゼロスタート(タイピング苦手でもOK) | 確定済みの第1話テーマ。script-video1-before-after.mdを実写ハイブリッドに改修して使用 |
| ショート2 | ChatGPT100選カテゴリまとめ①(投稿企画・ネタ出し系 #1-3) | content-calendar-100prompts.md 話1 |
| ショート3 | ChatGPT100選カテゴリまとめ②(業務効率化系 #71-73) | content-calendar-100prompts.md 話22相当。地域密着の職場ネタと絡めやすいカテゴリを優先 |

各ショートの末尾で「チャンネル登録して待っててください」「詳しくは概要欄の再生リストで」と誘導し、続きがあることを伝える。

---

## Phase3: 15分超の長尺動画1本(目安2-3週間)
ショート3本の反応・コメントを踏まえて、深掘り版の長尺動画を1本作る。

**構成案(15分目安)**
1. **自己紹介・独自ストーリー(0-3分)**: 地域密着企業で働きながら独学でAIに挑戦した経緯を、ショートより詳しく
2. **実演パート(3-10分)**: 音声入力を含む複数のAI活用シーンを実写画面録画で見せる(現場管理・顧客対応・シフト管理・請求書作成から2-3個)
3. **ChatGPT100選の紹介(10-13分)**: カテゴリをまたいで厳選した使えるプロンプトをまとめて紹介(保存版として機能させる)
4. **まとめ・チャンネル登録の呼びかけ(13-15分)**: 今後の投稿予定(週◯本ペース)を伝えて視聴を継続してもらう

**長尺動画の役割**: ショートで興味を持った人に「このチャンネルは本物だ」と思ってもらう保存版コンテンツ。視聴時間が伸びやすい構成(複数の実演を詰め込む)にすることが、収益化条件(視聴時間4000時間)の達成にも直結する。
