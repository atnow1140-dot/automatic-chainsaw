# YouTube ネタ帳（AI活用術・図なし構成）

> 方針: グラフ・図形を使わず、「実演・画面録画・数字テロップ・例え話・Before/After」だけで成立させる
> 作成日: 2026-09-26

---

## ネタ1: AIに1日の仕事を全部丸投げしてみた
- 概要: 朝から夜までの作業をすべてAIに振ってみる1日密着の検証動画
- 詳細:
  - 時刻テロップ（9:00 / 12:00 / 18:00）で時間の流れを見せるので、タイムラインの図はいらない
  - 各作業は「依頼 → AIの回答画面 → 使えた？使えなかった？」の3段階でテンポよく
  - 最後に「浮いた時間 ○時間」を大きな数字テロップで1回だけ出す
- 図なしの見せ方: 密着ドキュメント＋時刻テロップ
- 次のアクション: 丸投げする作業を5〜6個リストアップ → 撮影日を決める

## ネタ2: 同じ質問をAI3つに投げて本気で比べてみた
- 概要: ChatGPT・Claude・Gemini などに同じお題を出して回答を比べる企画
- 詳細:
  - 画面を3分割して回答を並べれば、比較表はいらない
  - お題は「旅行プラン」「謝罪メール」「動画タイトル案」など視聴者が使いそうなものを3問
  - 各問で自分の判定をひと言（「これは○○の勝ち」）→ 最後に総合優勝を発表
- 図なしの見せ方: 画面分割＋勝敗コメント
- 次のアクション: お題3問を確定 → 比べるAIを決める → 画面録画

## ネタ3: AIへの頼み方が下手な人・上手い人の違い
- 概要: 同じ依頼をNGプロンプトとOKプロンプトで投げて、結果の差を見せる
- 詳細:
  - 「雑な指示 → 微妙な回答」「具体的な指示 → 神回答」を実際の画面で並べる
  - 例え話:「AIは優秀な新人。『いい感じにやって』だと困る」
  - 上手い頼み方のコツを3つ、番号テロップで出す
- 図なしの見せ方: Before/After＋例え話
- 次のアクション: NG/OKのプロンプトを3組作る → 結果をスクショしておく

## ネタ4: 初心者がAIでやりがちな失敗5選
- 概要: 「嘘をそのまま信じる」「個人情報を入れる」などのあるある失敗をカウントダウンで紹介
- 詳細:
  - 第5位 → 第1位のカウントダウンで、口頭と番号テロップだけで構成
  - 各失敗に「実際に起きた画面」＋「こうすればOK」の対策をセットで
  - 共感系なので、コメント欄で「自分もやった」を集めやすい
- 図なしの見せ方: ランキング形式（番号テロップのみ）
- 次のアクション: 失敗5つを確定 → 実例の画面を用意

## ネタ5: AIだけで動画1本作ってみた（企画〜台本〜タイトル）
- 概要: 動画制作の流れを全部AIでやってみるメイキング系
- 詳細:
  - 「ネタ出し → 構成 → 台本 → タイトル → サムネ文言」を「STEP1〜5」のテロップで進める
  - 各STEPで「AIの案」と「採用した案・直した部分」を見せる → 人間の手の入れどころが伝わる
  - 最後に完成した動画をチラ見せするオチ
- 図なしの見せ方: STEP番号テロップ＋画面録画
- 次のアクション: 作る動画のテーマを1つ決める → 各STEPを録画しながら進める

## ネタ6: 家事・生活をAIで楽にする方法5選
- 概要: 仕事以外の「献立」「買い物リスト」「掃除の段取り」などの生活系AI活用
- 詳細:
  - 冷蔵庫の中身を写真で撮って献立を出してもらう、など実物を使った実演が中心
  - 実写（冷蔵庫・スーパー）とスマホ画面の切り替えでテンポを出す
  - 仕事系より幅広い層に刺さるので、新規の視聴者を取り込む用
- 図なしの見せ方: 実写＋スマホ画面の実演
- 次のアクション: 生活シーン5つを選ぶ → 実写で撮れる場所を確保

## ネタ7: AIに自分のチャンネルを辛口で分析させてみた
- 概要: 自分の動画タイトル・概要欄・台本をAIに見せて改善点を出してもらう
- 詳細:
  - 自分の実際のチャンネル画面を見せるので説得力が出る
  - AIの辛口コメントにリアクションするエンタメ要素（「痛いところ突かれた…」）
  - 指摘を1つ実際に直して、次回の動画で結果を報告すればシリーズ化できる
- 図なしの見せ方: 画面録画＋リアクション
- 次のアクション: 分析させる動画を3本選ぶ → プロンプトを作る

## ネタ8: 1万円の作業をAIで0円にできるか検証
- 概要: 外注したら費用がかかる作業（ロゴ・翻訳・文字起こしなど）をAIで代用できるか試す
- 詳細:
  - 「外注相場 ○円」→「AIなら 0円」を数字テロップで1回ずつ出すだけでインパクトは十分
  - 作業ごとに「使える / ギリ使える / プロに頼むべき」の3段階で判定
  - 正直な判定（ダメなものはダメと言う）で信頼感を出す
- 図なしの見せ方: 数字テロップ＋3段階判定
- 次のアクション: 検証する作業を3〜4つ選ぶ → 外注相場を調べておく

## ネタ9: AIを使いこなす人の1日ルーティン
- 概要: 自分がAIをどう日常に組み込んでいるかを見せるルーティン動画
- 詳細:
  - 朝・昼・夜の実写ルーティンに、AIを使う場面だけ画面録画を差し込む
  - ルーティン動画は保存・リピートされやすく、チャンネルの人柄も伝わる
  - BGM＋最小限のテロップで、しゃべりが少なくても成立する
- 図なしの見せ方: Vlog形式（実写＋画面の差し込み）
- 次のアクション: AIを使う場面を1日の中で5つ洗い出す → 撮影日を決める

## ネタ10: AIに100の質問をしてみた
- 概要: 視聴者から集めた質問や素朴な疑問を、AIにテンポよくぶつけていく企画
- 詳細:
  - 「Q.○○」のテロップ → AIの回答 → 自分のひと言 のくり返しで進むので構成がシンプル
  - 面白い回答・ズレた回答はオチとして後半に回す
  - 質問はInstagramのストーリーズで募集 → Instagramとの連動にもなる
- 図なしの見せ方: Q&Aテロップのくり返し
- 次のアクション: Instagramで質問を募集 → 質問を整理して並べる順を決める

- 準備が少し必要: ネタ5, 8, 10
- 撮影日の確保が必要（実写・1日密着）: ネタ1, 6, 9
