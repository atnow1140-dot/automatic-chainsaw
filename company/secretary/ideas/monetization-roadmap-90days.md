# 収益化までの逆算スケジュール(90日プラン)

## 概要
- 起点: 2026-09-20(今日) / ゴール: 2026-12-19(約13週間後)
- ゴール定義: 「初収益」を1件作る
  - 初収益の定義(仮): アフィリエイト成約1件 / 単発相談・PR案件1件 / 有料コンテンツ・テンプレ販売1件 のいずれか
  - フォロワー数など前提条件が不明なため、一般的なマイクロインフルエンサー基準で仮組み。実数値が分かり次第、週数を調整する
- ベース資料: 「ChatGPT最強プロンプト100選」(Instagram発信5カテゴリ + AI副業収益化5カテゴリ、計100個)
- 逆算ロジック: 収益発生 ← 導線・信頼・商品 ← フォロワー数/エンゲージ ← 投稿の型、の順で必要条件を遡って4フェーズ・13週に分解

## 現状(2026-09-20時点)
- ネタ出し3本(神プロンプト3選/無料AIツール3選/AI丸投げBefore-After)は完了済み
- 動画の台本作成は進行中 → Phase1 Week1に合流

## Phase 1: 土台作り(Week1-2 / 9/20〜10/3)
発信の軸と型を固めるフェーズ。ここが曖昧だと後工程が全部やり直しになる。

**Week1(9/20-9/26)**
- [ ] ターゲット顧客像を1枚にまとめる(#2)
- [ ] コンテンツの柱を4本決める(知識系/事例/雑談系など)(#3)
- [ ] 今ある3本のネタを台本化(進行中のタスク)

**Week2(9/27-10/3)**
- [ ] 1ヶ月分の投稿テーマカレンダーを作る(#5)
- [ ] リール30秒構成のテンプレを1個確定させる(#22)
- [ ] フック文の型を3パターン用意する(#11)
- [ ] Week1の台本を撮影→初投稿

**KPI目標**: 週4-5投稿のリズムが崩れず回せる状態。保存率・再生維持率の計測を開始(数値の良し悪しはまだ問わない)

---

## Phase 2: フォロワー増加・エンゲージ構築(Week3-6 / 10/4〜10/31)
量とデータを積むフェーズ。ここでフォロワー・保存数・コメントを伸ばす。

**Week3**
- [ ] ハッシュタグをリーチ幅別に整理して固定セット化(#31, #36)
- [ ] 投稿タイミングの仮説を立てる(#40)

**Week4**
- [ ] コメント返信・DM対応のテンプレを作って毎日回す(#41, #42)
- [ ] 週1インサイト振り返りを習慣化(#81)

**Week5**
- [ ] 伸びた投稿・伸びなかった投稿の要因分析(#82, #83)
- [ ] 投稿タイミング・ハッシュタグの仮説をA/B検証(#84)

**Week6**
- [ ] 月次振り返り(KPT)で10月の成果を整理(#85)
- [ ] 11月の優先アクションを3つ決める(#90)

**KPI目標(仮)**: フォロワー数が月次で二桁%成長、保存率が上昇傾向、DM/コメントで自発的な反応が週1件以上発生

## Phase 3: 収益化の導線構築(Week7-10 / 11/1〜11/28)
「売るもの」と「売る場所」を用意するフェーズ。フォロワーとの信頼が土台にある前提。

**Week7**
- [ ] 収益化フローを3パターン洗い出して優先順位を付ける(#52)
- [ ] アフィリエイトASP候補を5つ選定する(#63)

**Week8**
- [ ] 提供できる知見をコンテンツ商品(電子書籍/テンプレ等)の構成案に落とす(#53, #64)
- [ ] 簡易キャッシュフロー試算で数字を確認する(#55)

**Week9**
- [ ] フロント商品(初回相談・体験など)を1つ設計する(#66)
- [ ] プロフィール文(bio)に導線を入れて更新する(#20)

**Week10**
- [ ] 無料プレゼント/特典を1つ用意してリスト化の入口を作る(#67)
- [ ] 事業アイデアの弱点を厳しめにチェック(壁打ち)(#56)

**KPI目標**: 「これ買ってください/申し込んでください」と言える商品・導線が1つ完成し、bio経由のクリック/アクセスが計測できる状態

---

## Phase 4: 収益化クロージング(Week11-13 / 11/29〜12/19)
実際に告知・提案して収益に変える最終フェーズ。

**Week11**
- [ ] 価格設定を3プランで最終決定する(#61)
- [ ] セールス文・LP構成を仕上げる(#65)

**Week12**
- [ ] フロント商品 or アフィリエイトの告知投稿を作成・実行する(#62, #67)
- [ ] 反応を見て告知文・導線を1回リライト

**Week13**
- [ ] 反応が薄い箇所を特定し最終調整(#86 伸び率予測チェック)
- [ ] 初成約・初売上が出たら振り返りログを残す
- [ ] 継続化フェーズへの月次ロードマップを作る(#70)

**KPI目標**: 初収益1件達成
