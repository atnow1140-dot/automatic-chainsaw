# 真面目の芽 ― 大人のための静かな学び｜YouTubeチャンネル説明文案

作成日: 2026-09-27

## 前提（YouTube仕様）
- 説明文は最大1000文字
- 検索結果・チャンネルページのプレビューで見えるのは冒頭の約100〜150字 → 最初の2行で「何のチャンネルか」を言い切る
- 検索に拾われやすいキーワード（教養・学び直し・雑学・歴史・言葉 など）を自然に入れる

## A案：王道・SEO重視（おすすめ）
```
大人のための、静かな学びのチャンネルです。
歴史・言葉・教養・心理・暮らしの知恵を、落ち着いた語りでわかりやすくお届けします。

「学び直したいけど、騒がしい動画は疲れる」
そんな方に向けて、煽らず、急かさず、
聞き流すだけで少し賢くなれる時間をつくっています。

▼ こんな方におすすめ
・大人になってから学び直したい
・寝る前や作業中に、落ち着いた声で教養を聞きたい
・雑学より一歩深い「なるほど」が欲しい

▼ 主なテーマ
歴史の裏話／言葉・日本語の由来／哲学・思考のヒント／心理学／暮らしと文化

🌱 毎週〇曜日 〇時更新
気に入っていただけたら、チャンネル登録で次の「芽」を受け取ってください。

#教養 #学び直し #大人の学び #雑学 #作業用 #睡眠用
```

## B案：語りかけ・世界観重視
```
静かに、真面目に、少しずつ。
「真面目の芽」は、大人の知的好奇心に小さな芽を育てる学びのチャンネルです。

忙しい毎日のなかで、ふと立ち止まって考える時間。
歴史、言葉、哲学、文化――
知っていると世界が少しだけ深く見える話を、ゆっくりとお話しします。

通勤中に、家事をしながら、眠る前に。
あなたの一日に、静かな学びをひとつ。

🌱 毎週〇曜日更新
📩 お仕事のご依頼：（メールアドレス）
```

## C案：短く簡潔
```
大人のための静かな学び。
歴史・言葉・教養を、落ち着いた語りで10分前後にまとめています。
聞き流しでも、じっくりでも。今日の「なるほど」をひとつ。

🌱 毎週〇曜日更新
```

## 使い分けメモ
- 伸ばしたい・検索から人を呼びたい → A案
- ブランドの世界観を大事にしたい → B案
- 動画の中身で語らせたい → C案
- 更新曜日・動画尺・テーマ・連絡先は実運用に合わせて書き換える
- 「睡眠用」「作業用」タグは、実際に聞き流し向けの作りにする場合のみ入れる
