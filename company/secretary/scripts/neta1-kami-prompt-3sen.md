# 台本: 神プロンプト3選（時短系）

- 元ネタ: ideas/instagram-ai-tips-neta.md「ネタ1」
- 形式: リール（縦型 9:16）
- 尺の目安: 40〜45秒
- 狙い: 保存される（プロンプト全文を画面に出す）
- ステータス: 初稿

---

## 構成

| # | 秒数 | パート | 画面 | テロップ / ナレーション |
|---|------|--------|------|------------------------|
| 1 | 0〜3秒 | フック | 顔出し or 散らかったメール画面 | 「これ知らない人、毎日30分ムダにしてる」 |
| 2 | 3〜5秒 | 予告 | テロップのみ | 「AIに投げるだけの神プロンプト3選」<br>「保存して使って」 |
| 3 | 5〜15秒 | ①メール返信 | Before: 手打ちで悩む → After: AIが下書き | 「①メール返信、もう考えなくていい」 |
| 4 | 15〜25秒 | ②長文の要約 | Before: 長い資料をスクロール → After: 3行で要約 | 「②長い資料は3行で読む」 |
| 5 | 25〜37秒 | ③企画のたたき台 | Before: 白紙のメモ → After: 企画案10個 | 「③アイデア出しはAIにやらせる」 |
| 6 | 37〜43秒 | まとめ・CTA | 3つのプロンプトを一覧表示 | 「全部画面に載せたから保存しといて」<br>「次は『無料AIツール3選』やるからフォローしてね」 |

## 画面に出すプロンプト全文

### ① メール返信
```
以下のメールに返信したいです。
・返信の方向性：【OK／お断り／日程調整 など】
・相手との関係：【取引先／上司／友人 など】
丁寧すぎず、3〜5行で返信文を作って。

【ここにメール本文を貼る】
```

### ② 長文の要約
```
以下の文章を
1. 3行で要約
2. 自分がやるべきこと（あれば）
の2つに分けてまとめて。

【ここに文章を貼る】
```

### ③ 企画のたたき台
```
あなたはSNSの企画担当です。
テーマ：【例：カフェ巡り】
ターゲット：【例：20代社会人】
Instagramで伸びそうな企画案を10個、
それぞれ「タイトル＋一言説明」で出して。
```

## 撮影メモ
- Before は2〜3秒で切る（ダラダラ見せない）
- After は生成される瞬間を画面録画で見せる（倍速OK）
- プロンプト全文は各パートの最後に1秒以上静止させる（スクショされやすい）
- 最後の一覧画面はカルーセル投稿にも流用できる
